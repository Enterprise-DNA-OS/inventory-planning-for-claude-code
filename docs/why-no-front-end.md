# Why no front end

A planner can review replenishment, stock cover, supplier delays and records by asking the coding agent to run the CLI. The database, forecast method and history are inspectable. HTML reports and paperwork are snapshots made from the same records.

Netstock includes forecasting, planning screens, reporting and integrations. This free build implements a bounded, explicit replenishment method; it does not reproduce every vendor feature. See planning-method.md.

A web application adds forms, interactive charts, access management and shared workflows. A mobile app adds a phone interface, offline capture and notifications. This version has no drag-and-drop plan, live supplier feed, mobile workflow or built-in scheduled synchronization. The local database works offline after dependencies are installed; the chosen agent can still require a network connection.

Enterprise DNA builds the agreed front end, integrations and controls into a custom version and operates it through Omni by Enterprise DNA. Generated reports remain private files unless the operator separately authorises sharing.
