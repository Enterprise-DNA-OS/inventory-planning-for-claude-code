# Weekly Review

Read CLAUDE.md. Run `npm run planning -- weekly-review` with the operator's supplied values. Add `--json` when collecting results. Resolve names with `list`; ambiguous references must be clarified with the operator. Never invent an actor, evidence, date or result.

Present the result, the stock date and any blocked inputs. Label all order suggestions and documents as drafts. Never send, place an order, change a supplier system or delete records.

Run buy-plan, attention and supplier-review separately as well. Summarise what to buy, what needs a confirmed arrival date and what is blocked. Group money by currency. Ask for human decisions before recording changes.
